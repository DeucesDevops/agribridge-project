# ADR 0001: Run the cluster with kOps

## Status

Accepted.

## Context

AgriBridge needs one Kubernetes cluster in `us-east-1` for production. The
application, DNS, buckets, IAM, and add-ons are already described in Terraform.
The cluster name is `k8s.agribridge.deuces.dev`. The public zone is
`agribridge.deuces.dev`.

The control plane has to be created with the same reviewable change as the VPC,
the node IAM, and the state the nodes boot from. A split between a hosted
control plane and a separate node stack would leave the certificates, the
issuer, and the instance configuration in different places.

## Decision

Use kOps 1.36.2. The cluster is `kops/cluster.yaml`. `scripts/render-kops-terraform.sh`
runs `kops update cluster --target=terraform` and
`scripts/patch_kops_terraform.py` splits that output into
`terraform/modules/network` and `terraform/modules/cluster`. The production
root applies those modules with DNS, storage, identity, and, on a second
apply, the platform Helm releases.

kOps writes the cluster certificates into `s3://kops-state-607` in the same
run that renders the Terraform which uploads node configuration. Those two
have to match, so the apply script refreshes the modules before it applies.

The spec keeps the choices the cluster already runs with: public subnets and
no NAT gateway, Calico, no SSH key, an API on port 443, the EBS CSI driver,
the AWS Load Balancer Controller, and a service-account issuer in the
discovery bucket. Pod identity uses that issuer and the audience
`amazonaws.com`.

## Consequences

- Changing the cluster means editing `kops/cluster.yaml`, rendering, and
  reviewing the Terraform diff. The rendered files are committed.
- The GitHub Actions role can still read the state bucket and export an admin
  kubeconfig. Treat that role as cluster-admin. The image-tag job does not
  assume it.
- Add-ons that kOps owns stay in the rendered modules. Argo CD, External
  Secrets, ExternalDNS, Prometheus, Grafana, Loki, and Promtail are the
  platform module, installed only after the API answers.
